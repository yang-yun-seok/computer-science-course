# 용어 팝업 문맥 검수 — 2026-10-31

## 범위와 방법

- 전체 48개 교안의 도입·학습 목표·본문·정리에 실제 생성되는 용어 버튼을 브라우저에서 추출했다.
- 기존 연결 1,601곳과 고유 항목 300개를 용어별로 묶어 정의와 대조했다. 약어·동음어·일반어는 주변 문장과 함께 판정했다.
- 실습 내부 조작부·코드·퀴즈·그림 설명은 기존과 같이 자동 연결 대상에서 제외한다.
- 이번 검수는 팝업에 쓰이는 정의와 연결이 대상이다. 용어집 전체 1,151개 항목을 모두 새로 검증했다는 뜻은 아니다.

## 결과

- 기존 표시어 기준: 연결 유지 1,185곳, 다른 뜻으로 교정 103곳, 자동 표시 해제 313곳. 유지 수에는 정의 문장을 고친 항목도 포함된다.
- 정의 88개를 교정하고 서로 다른 뜻을 구별할 항목 18개를 추가했다.
- 최종 실제 화면: 48개 교안에 1,300개 버튼, 고유 항목 290개. 긴 용어를 통째로 표시하거나 주제별 중복을 정리하므로 기존 연결 수와 단순 차감한 수는 다르다.
- 일반적으로 쓰인 말이나 맞는 용어집 항목이 없는 경우에는 뜻을 억지로 연결하지 않는다.
- [문장별 판정 기록](검수/용어팝업_연결검수.csv)에 기존 위치·표시어·항목·변경 결과와 주변 문장을 보관했다.
