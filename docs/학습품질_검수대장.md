## 1. 사용 규칙

- 아래 0/N은 이번 계획에 따른 완료 수다. 기존 교안·실습이 미구현이라는 뜻이 아니다.
- A 주제는 b01~b06 각각의 본문·그림·실습·요약 연결을 확인한 뒤 센다.
- A 확인 문제는 기존 questions 3개 각각을 확인한 뒤 센다.
- B 문항 1개 완료는 3개 선택지·정답·오답 해설·본문 연결·버전 처리까지 끝낸 상태다.
- C 미션 1개 완료는 A/B 조건·기대값·실제 조작·결과 기록·설명 기준까지 확인한 상태다.
- 그림 수는 전체 자산 개수가 아니라 해당 주제에 실제 표시되는 독립 그림을 기준으로 기록한다. 아직 수량을 직접 검수하지 않았으므로 별도 확인 전에는 완료로 세지 않는다.
- 자동 검사 통과만으로 A나 B의 편집 검토 상태를 완료로 올리지 않는다.
- 원래 4번의 전 과정 모바일·키보드 점검은 이 대장의 집계에 포함하지 않는다.
